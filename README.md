# mine.d-app

## manage-customers.html — AIVO 고객관리

업종을 가리지 않고 **고객을 만들고 · 관리하고 · 넓혀가는 전 과정(A→Z)** 을
하루에 하나씩 실행하게 해 주는 모바일 웹 앱. 단일 HTML 파일이라 그대로 열거나 정적 호스팅에 올리면 됩니다.

### 디자인
- 아이보리 · 차콜 · 골드 3색 팔레트, 제목은 명조(Noto Serif KR) + 본문은 Pretendard
- 이모지 대신 선 아이콘 SVG 45종
- **밝게 / 어둡게 / 기기 설정 따라** — 헤더에서 즉시 전환
- PWA 매니페스트·앱 아이콘, 세이프에어리어 대응

### 두 가지 사용 방식
| 모드 | 하는 일 |
|---|---|
| **집중 · 하나씩** | 오늘 할 일 중 가장 급한 것 **딱 하나만** 보여주고, 완료하면 다음으로 |
| **전체 대시보드** | 파이프라인 퍼널 · 매출 진척 · 성사율 · 연락 지연 · 7일 활동 · 오늘 할 일 전체 |

### 고객관리 엔진
- **파이프라인 6단계 + 보류** (신규 → 연결 → 니즈확인 → 제안 → 협상 → 성사)
- **단계별 연락 주기(케이던스)** 자동 계산 → 때가 되면 먼저 알림
- **접촉 8회 게이지** — 계약까지 평균 8회 접촉이 필요하다는 기준을 시각화
- **정체 감지** — 한 단계에 오래 멈춘 고객을 찾아 밀거나 정리하도록 유도
- **생일·기념일** — 3일 전부터 축하 인사 대본과 함께 실행 목록에 등장

### 기능
- **연락 일정** — 주간 캘린더로 할 일·연락·기념일을 날짜별로
- **매출 관리** — 성사 금액 자동 집계, 월 목표 진척, 최근 6개월 추이
- **주간 리포트**(프로) — 접촉·실행·성사·다음 주 예정 + 코치 총평
- **연락처 일괄 등록** — 이름을 붙여넣으면 한 번에 (쉼표로 소속·전화 인식)
- **상황별 대본 12종** — 받는 분을 고르면 이름이 자동으로 채워지고 문자 앱으로 바로 연결
- **음성 기록 → AI 요약·코칭·할 일 자동 생성** (오프라인 대체 로직 내장)
- **빠른 메모** — 고객 카드에서 한 줄(또는 음성)로 즉시 기록
- **매일 알림** — 정한 시각에 오늘 할 일을 알려줌 (앱이 열려 있을 때)
- **백업 내보내기 / 불러오기** — 기기를 바꿔도 그대로 복원
- 교육센터 3단계 12과

### 수익화
- `ADS` 상수에 AdMob(앱) / AdSense(웹) 단위 ID를 넣으면 배너·전면·보상형 광고가 붙습니다.
- 무료: 고객 15명 · AI 하루 5회 · 교육 1단계 · 광고 노출 (광고 시청 시 AI 3회 충전)
- 프로: 무제한 · 광고 제거 · 전체 교육/대본 · 매출 심화 분석 · 주간 리포트 · 팀 관리 · 내보내기

### 배포 시 주의
`AI_ENDPOINT` 는 데모용으로 Anthropic API를 직접 호출합니다.
실제 배포에서는 **서버리스 프록시(예: `/api/ai`)로 바꿔** API 키가 노출되지 않게 하세요.
호출이 실패해도 앱은 간단 코칭 모드로 계속 동작합니다.

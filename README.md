# mine.d-app

## manage-customers.html — AIVO 고객관리

업종을 가리지 않고, **고객을 만들고 · 관리하고 · 넓혀가는 전 과정(A→Z)** 을 하루에 하나씩
실행하게 해 주는 모바일 웹 앱입니다. 단일 HTML 파일이라 그대로 열거나 정적 호스팅에 올리면 됩니다.

### 두 가지 사용 방식
| 모드 | 하는 일 |
|---|---|
| **집중 · 하나씩** | 오늘 해야 할 일 중 가장 급한 것 **딱 하나만** 보여주고, 완료하면 다음으로 넘어감 |
| **전체 대시보드** | 파이프라인 퍼널 · 예상 매출 · 성사율 · 연락 지연 · 7일 활동 · 오늘 할 일 전체를 한눈에 |

### 고객관리 엔진
- **파이프라인 6단계 + 보류** (신규 → 연결 → 니즈확인 → 제안 → 협상 → 성사) — 소규모 사업 권장 범위
- **단계별 연락 주기(케이던스)** 자동 계산 → 때가 되면 먼저 알려줌
- **접촉 8회 게이지** — 계약까지 평균 8회 접촉이 필요하다는 기준을 시각화
- **정체 감지** — 한 단계에 오래 멈춘 고객을 찾아 밀거나 정리하도록 유도
- 음성 기록 → AI가 요약·코칭·다음 할 일 자동 생성 (오프라인 대체 로직 내장)
- 교육센터 3단계 12과 + 상황별 대본 12종

### 수익화
- `ADS` 상수에 AdMob(앱) / AdSense(웹) 단위 ID를 넣으면 배너·전면·보상형 광고가 붙습니다.
- 무료: 고객 15명 · AI 하루 5회 · 교육 1단계 · 광고 노출
- 프로: 무제한 · 광고 제거 · 전체 교육/대본 · 심화 분석 · 팀 관리 · 내보내기

### 배포 시 주의
`AI_ENDPOINT` 는 데모용으로 Anthropic API를 직접 호출합니다.
실제 배포에서는 **서버리스 프록시(예: `/api/ai`)로 바꿔** API 키가 노출되지 않게 하세요.
호출이 실패해도 앱은 간단 코칭 모드로 계속 동작합니다.
